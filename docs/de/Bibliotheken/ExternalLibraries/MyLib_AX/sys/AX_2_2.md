# AX_2_2

![AX_2_2_network](./AX_2_2_network.svg)

* * * * * * * * * *

## Einleitung

`AX_2_2` verodert zwei AX-Adapter-Eingänge (`IN1`, `IN2`) und verteilt das Ergebnis auf zwei AX-Adapter-Ausgänge (`OUT1`, `OUT2`) — eine "2-zu-2"-Verschaltung für Fälle, in denen zwei unabhängige boolesche Quellen kombiniert und das Ergebnis an zwei unabhängige Ziele weitergegeben werden muss.

## Verwendete Funktionsbausteine (FBs)

### Sub-Bausteine: AX_2_2

- **Typ**: SubAppType
- **Verwendete interne FBs**:
    - **AX_OR_2**: `adapter::booleanOperators::AX_OR_2` — ODER-Verknüpfung zweier Adapter-Eingänge.
    - **AX_SPLIT_2**: `adapter::events::unidirectional::AX_SPLIT_2` — verzweigt das ODER-Ergebnis auf zwei Ausgänge.
- **Funktionsweise**: `IN1 OR IN2` → `OUT1` und `OUT2` gleichzeitig.

## Programmablauf und Verbindungen

1. `IN1` → `AX_OR_2.IN1`, `IN2` → `AX_OR_2.IN2`.
2. `AX_OR_2.OUT` → `AX_SPLIT_2.IN`.
3. `AX_SPLIT_2.OUT1` → `OUT1`, `AX_SPLIT_2.OUT2` → `OUT2`.

## Anwendungsszenarien

- Jede Stelle, an der zwei unabhängige Bool-Adapter-Quellen ODER-verknüpft und das gemeinsame Ergebnis an zwei unabhängige Verbraucher (z. B. zwei VT-Statusanzeigen) weitergereicht werden muss, ohne eine doppelte Adapterverbindung anzulegen.

## Zusammenfassung

`AX_2_2` ist ein minimaler Baustein für "zwei Quellen ODER-verknüpfen, an zwei Ziele verteilen" — reine Adapter-Verdrahtung ohne eigene Zustandslogik.
