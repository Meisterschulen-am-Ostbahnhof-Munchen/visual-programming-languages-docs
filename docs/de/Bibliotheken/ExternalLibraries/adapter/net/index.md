# net

Hier finden Sie Funktionsbausteine, die die Netzwerk-Kommunikation (Publish/Subscribe) auf die unidirektionalen AX-Adapter abbilden. Die Bausteine kapseln die entsprechenden `iec61499::net`-Funktionsbausteine und puffern die übertragenen BOOL-Werte mit einem D-Flipflop.
