# sys (test_B)

Eigenständige `MyLib::sys`-Bausteinbibliothek des Trainingssystems `test_B` — keine Namensüberschneidung mit [MyLib (test_AX)](../../MyLib_AX/index.md). Siehe insbesondere [Background-Farbbausteine (gemeinsames Muster)](../../MyLib_AX/sys/Background-Farbbausteine.md) für die große Familie der Hintergrundfarb-Bausteine, die es hier ohne `_AX`-Suffix gibt (Selector als `BOOL` statt Adapter).
