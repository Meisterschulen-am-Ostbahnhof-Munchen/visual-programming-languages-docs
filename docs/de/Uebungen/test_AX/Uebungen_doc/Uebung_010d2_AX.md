# Uebung_010d2_AX: Toggle-Flipflop mit SoftKey_F1 und GreenWhiteBackground mit Typed Subapp

Dieser Artikel beschreibt die logiBUS®-Übung `Uebung_010d2_AX`.

----

## Ziel der Übung

Wiederverwendbarkeit durch Typisierung.

-----

## Beschreibung

Hier wurde aus der untypisierten Toggle-Flipflop-Schaltung aus `Uebung_010d_AX` ein echter Typ `Uebung_010d2_sub_AX` erstellt.
Er hat Parameter `u16ObjId` (welcher Softkey?) und `Output` (welcher Ausgang?).

-----

## Vorteil

Man kann diesen "Smart Toggle-Softkey"-Baustein nun beliebig oft in der Bibliothek verwenden.
