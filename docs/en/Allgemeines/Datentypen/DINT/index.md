# Data Type Details: DINT
## Description
Double Integer
## Normative Definition
According to **DIN EN 61131-3**, this data type is specified as follows:
| Property | Value |
| :--- | :--- |

| **Bits** | 32 |

| **Value Range** | -2,147,483,648 to 2,147,483,647 |

| **Reference** | Table 10, No. 4 |

## Use in Programming
In IEC 61131-3 and IEC 61499, this type is used for declaring variables and in function blocks.

When used as a literal, a prefix can be used, e.g., `DINT#...`.
