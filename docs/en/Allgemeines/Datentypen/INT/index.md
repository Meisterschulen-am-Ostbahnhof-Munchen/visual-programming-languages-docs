# Data Type Details: INT

## Description

Integer

## Normative Definition

According to **DIN EN 61131-3**, this data type is specified as follows:

| Property | Value |
| :--- | :--- |
| **Bits** | 16 |
| **Value Range** | -32,768 to 32,767 |
| **Reference** | Table 10, No. 3 |

## Use in Programming

In IEC 61131-3 and IEC 61499, this type is used for declaring variables and in function blocks.

When used as a literal, a prefix can be used, e.g., `INT#...`.
