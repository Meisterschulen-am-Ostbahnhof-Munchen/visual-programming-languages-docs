# Data Type Details: LWORD
## Description
Bit sequence of length 64
## Normative Definition
According to **DIN EN 61131-3**, this data type is specified as follows:
| Property | Value |
| :--- | :--- |

| **Bits** | 64 |

| **Value Range** | Bit sequence (64 bits) |

| **Reference** | Table 10, No. 21 |

## Use in Programming
In IEC 61131-3 and IEC 61499, this type is used for declaring variables and in function blocks.

When used as a literal, a prefix can be used, e.g., `LWORD#...`.
