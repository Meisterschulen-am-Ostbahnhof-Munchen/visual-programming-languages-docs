# Data Type Details: REAL

## Description

Real Number
## Normative Definition

According to **DIN EN 61131-3**, this data type is specified as follows:
| Property | Value |
| :--- | :--- |
| **Bits** | 32 |
| **Value Range** | Floating point according to IEC 60559 |
| **Reference** | Table 10, No. 10 |

## Use in Programming

In IEC 61131-3 and IEC 61499, this type is used for declaring variables and in function blocks.

When used as a literal, a prefix can be used, e.g., `REAL#...`.
