# Data Type Details: ULINT
## Description
Unsigned long integer
## Normative Definition
According to **DIN EN 61131-3**, this data type is specified as follows:
| Property | Value |
| :--- | :--- |

| **Bits** | 64 |

| **Value Range** | 0 to 2^64-1 |

| **Reference** | Table 10, No. 9 |

## Use in Programming
In IEC 61131-3 and IEC 61499, this type is used for declaring variables and in function blocks.

When used as a literal, a prefix can be used, e.g., `ULINT#...`.
