# Data Type Details: WORD

## Description

Bit sequence of length 16

## Normative Definition

According to **DIN EN 61131-3**, this data type is specified as follows:

| Property | Value |
| :--- | :--- |
| **Bits** | 16 |
| **Value Range** | Bit sequence (16#0000 to 16#FFFF) |
| **Reference** | Table 10, No. 19 |

## Use in Programming

In IEC 61131-3 and IEC 61499, this type is used for declaring variables and in function blocks.

When used as a literal, a prefix can be used, e.g., `WORD#...`.
