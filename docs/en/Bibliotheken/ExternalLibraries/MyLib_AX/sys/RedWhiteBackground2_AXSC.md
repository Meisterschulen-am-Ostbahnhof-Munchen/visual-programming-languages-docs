# RedWhiteBackground2_AXSC

* * * * * * * * * *

## Introduction

`RedWhiteBackground2_AXSC` is a **compact wrapper** around [`RedWhiteBackground2_AXS`](RedWhiteBackground2_AXS.md) — passes `u16ObjId`s and the selector straight through, without exposing the `CNF` event outputs and diagnostic values (`STATUS_n`, `u8OldColour_n`, `result_n`).

For the shared pattern, see [Background Color Blocks (shared pattern)](./Background-Color-Blocks.md).

## Summary

A pure pass-through to `RedWhiteBackground2_AXS` for the common case where the diagnostic values aren't needed.
