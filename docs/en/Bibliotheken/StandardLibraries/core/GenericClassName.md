# GenericClassName

* * * * * * * * * *
## Introduction

The attribute declaration `GenericClassName` defines the class name for generic types in 4diac.
## Technical Details

- **Base Data Type:** `STRING`
- **Initial Value:** `'GEN_'`
- **Usage:** Applied at the `FBType` level to identify generic implementations.
