# TypeHash

* * * * * * * * * *
## Introduction

The attribute declaration `TypeHash` defines a fixed type hash for function blocks.
## Technical Details

- **Base Data Type:** `STRING`
- **Initial Value:** `''` (empty)
- **Use:** Used to identify and validate type versions.
