**The EQ Operator in IEC 61499: An Introduction**

IEC 61499 is a standard that deals with function block modeling for industrial process measurement and control systems. It provides a framework for developing distributed control systems based on the use of function blocks. A central element of this standard is the definition of operators used in the function blocks to perform logical and arithmetic operations. One of these operators is the EQ operator, which will be examined in more detail in this paper.

### What is the EQ operator?

The EQ operator, also known as the equality operator, is a logical operator used to check whether two values are equal. In IEC 61499, this operator is frequently used in function blocks to evaluate conditions and make decisions. The EQ operator compares two input values and returns a Boolean value (TRUE or FALSE) depending on whether the values are equal or not.

### Syntax and Usage

In IEC 61499, the EQ operator is typically used in the expressions of function blocks. The syntax of the EQ operator is simple:

EQ(Eingang1, Eingang2)
Here, `Eingang1` and `Eingang2` are the two values to be compared. The operator returns `TRUE` if `Eingang1` and `Eingang2` are equal; otherwise, the return value is `FALSE`.
