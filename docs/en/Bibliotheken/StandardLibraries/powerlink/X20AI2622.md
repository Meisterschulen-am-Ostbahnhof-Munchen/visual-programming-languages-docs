# X20AI2622

* * * * * * * * * *

## Introduction
The X20AI2622 function block provides an interface for analog inputs in the openPOWERLINK fieldbus. It corresponds to the B&R X20AI2622 module.

![X20AI2622](X20AI2622.svg)

## Interface Structure

### **Event Inputs**
- **INIT**: Service initialization.

- **REQ**: Request to update input data.

### **Event Outputs**

- **INITO**: Initialization confirmation.

- **CNF**: Request to update the input data.

### **Data Inputs**

- **QI** (BOOL): Qualifier for INIT and REQ.

- **CNID** (USINT): Client Node ID (address of the node in the POWERLINK network).

- **MODID** (UINT): Module ID (position of the module in the node).

### **Data Outputs**

- **QO** (BOOL): Qualifier for outputs.

- **CNIDO** (USINT): Confirmed Client Node ID.

- **STATUS** (STRING): Network status.

- **AI01** (INT): Analog input 01.

- **AI02** (INT): Analog input 02.

## Functionality
After initialization with `CNID` and `MODID`, the function block outputs the current analog values of the physical module at outputs `AIxx` every `REQ`.
