# X20AI4622
* * * * * * * * * *
## Introduction
The X20AI4622 function block provides an interface for analog inputs in the openPOWERLINK fieldbus. It corresponds to the B&R X20AI4622 module with 4 analog inputs.
![X20AI4622](X20AI4622.svg)
## Interface Structure

### **Event Inputs**
- **INIT**: Service initialization.
- **REQ**: Request to update input data.

### **Event Outputs**
- **INITO**: Initialization confirmation.
- **CNF**: Request to update the input data.

### **Data Inputs**
- **QI** (BOOL): Qualifier for INIT and REQ.
- **CNID** (USINT): Client Node ID.
- **MODID** (UINT): Module ID.

### **Data Outputs**
- **QO** (BOOL): Qualifier for outputs.
- **CNIDO** (USINT): Confirmed Client Node ID.
- **STATUS** (STRING): Network status.
- **AI01** (INT): Analog input 01.
- **AI02** (INT): Analog input 02.
- **AI03** (INT): Analog input 03.
- **AI04** (INT): Analog input 04.

## Functionality
After initialization, the module provides the current analog values of the four channels.
