# X20AT2402
* * * * * * * * * *
## Introduction
The X20AT2402 function block is used to read temperature values via the openPOWERLINK fieldbus. It corresponds to the B&R X20AT2402 temperature input module (2 channels).
![X20AT2402](X20AT2402.svg)
## Interface Structure

### **Event Inputs**
- **INIT**: Initialization.
- **REQ**: Request data update.

### **Event Outputs**
- **INITO**: Initialization confirmed.
- **CNF**: New temperature data available.

### **Data Inputs**
- **QI** (BOOL): Qualifier.
- **CNID** (USINT): Client Node ID.
- **MODID** (UINT): Module ID.

### **Data Outputs**
- **QO** (BOOL): Qualifier.
- **CNIDO** (USINT): Confirmed Node ID.
- **STATUS** (STRING): Status.
- **T01** (REAL): Temperature input 01 (typically in °C, depending on module configuration).
- **T02** (REAL): Temperature input 02.

## Functionality
Reads temperature values from the physical module and provides them as REAL values.
