# X20AT4222

* * * * * * * * * *
## Introduction

The X20AT4222 function block is used to read temperature values via the openPOWERLINK fieldbus. It corresponds to the B&R X20AT4222 temperature input module (4 channels).
![X20AT4222](X20AT4222.svg)
## Interface Structure

### **Event Inputs**

- **INIT**: Initialization.
- **REQ**: Request data update.

### **Event Outputs**

- **INITO**: Initialization confirmed.
- **CNF**: New temperature data available.

### **Data Inputs**

- **QI** (BOOL): Qualifier.
- **CNID** (USINT): Client Node ID.
- **MODID** (UINT): Module ID.

### **Data Outputs**

- **QO** (BOOL): Qualifier.
- **CNIDO** (USINT): Confirmed Node ID.
- **STATUS** (STRING): Status.
- **T01** (REAL): Temperature Input 01.
- **T02** (REAL): Temperature Input 02.
- **T03** (REAL): Temperature Input 03.
- **T04** (REAL): Temperature Input 04.

## Functionality

Reads temperature values from the physical module and provides them as real values.
