# X20DI4653

* * * * * * * * * *

## Introduction

The X20DI4653 function block is used to read digital signals via the openPOWERLINK fieldbus. It corresponds to the B&R X20DI4653 digital input module (4 channels).
![X20DI4653](X20DI4653.svg)

## Interface Structure

### **Event Inputs**

- **INIT**: Initialization.
- **REQ**: Update input data.

### **Event Outputs**

- **INITO**: Initialization confirmed.
- **CNF**: New data available.

### **Data Inputs**

- **QI** (BOOL): Qualifier.
- **CNID** (USINT): Client Node ID.
- **MODID** (UINT): Module ID.

### **Data Outputs**

- **QO** (BOOL): Qualifier.
- **CNIDO** (USINT): Confirmed Node ID.
- **STATUS** (STRING): Status.
- **DI01** (BOOL): Digital Input 01.
- **DI02** (BOOL): Digital Input 02.
- **DI03** (BOOL): Digital Input 03.
- **DI04** (BOOL): Digital Input 04.

## Functionality

Reads the state of the digital inputs from the module and provides them as Boolean values.
