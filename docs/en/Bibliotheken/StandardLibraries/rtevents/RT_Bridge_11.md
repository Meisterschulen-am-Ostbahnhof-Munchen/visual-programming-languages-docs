# RT_Bridge_11

* * * * * * * * * *

## Introduction
The RT_Bridge_11 function block serves as a decoupling bridge for 11 data connections between real-time event chains.

## Interface Structure

### **Event Inputs**
- **RD**: Read data.

- **WR**: Write data.

### **Event Outputs**
- **RDO**: Read acknowledgment.

### **Data Inputs**
- **SD_1** - **SD_11** (ANY): Input data.

### **Data Outputs**
- **RD_1** - **RD_11** (ANY): Output data.
