# RT_Bridge_5

* * * * * * * * * *

## Introduction

The RT_Bridge_5 function block serves as a decoupling bridge for 5 data connections between real-time event chains.

## Interface Structure

### **Event Inputs**

- **RD**: Read data.
- **WR**: Write data.

### **Event Outputs**

- **RDO**: Read acknowledgment.

### **Data Inputs**

- **SD_1** - **SD_5** (ANY): Input data.

### **Data Outputs**

- **RD_1** - **RD_5** (ANY): Output data.
