# Exercise_010d2_AX: Toggle flip-flop with SoftKey_F1 and GreenWhiteBackground using a Typed Subapp

This article describes the logiBUS® exercise `Uebung_010d2_AX`.

----

## Goal of the exercise

Reusability through typing.

-----

## Description

Here, the untyped toggle flip-flop circuit from `Uebung_010d_AX` was turned into a real type, `Uebung_010d2_sub_AX`.
It has the parameters `u16ObjId` (which softkey?) and `Output` (which output?).

-----

## Benefit

This "smart toggle softkey" block can now be reused as often as needed in the library.
