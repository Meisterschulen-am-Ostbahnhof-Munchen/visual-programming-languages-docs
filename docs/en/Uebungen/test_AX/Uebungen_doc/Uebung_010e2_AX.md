# Exercise_010e2_AX: SR+Toggle flip-flop with 3x SoftKey and GreenWhiteBackground using a Typed Subapp

This article describes the logiBUS® exercise `Uebung_010e2_AX`.

----

## Goal of the exercise

Reusability through typing.

-----

## Description

Here, the untyped SR+toggle flip-flop circuit from `Uebung_010e_AX` was turned into a real type, `Uebung_010e2_sub_AX`.
It has the parameters `u16ObjId_SET`, `u16ObjId_RESET`, `u16ObjId_TOGGLE` (which softkey triggers which action?) and `Output` (which output?).

-----

## Benefit

This "smart SR+toggle softkey" block can now be reused as often as needed in the library.
