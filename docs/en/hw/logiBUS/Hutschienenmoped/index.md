# DIN Rail Controller Overview

The DIN Rail Controller: Compact Controller for DIN Rails
Our "DIN Rail Controller" is the ideal solution for anyone needing a compact, flexible, and cost-effective controller directly in the control cabinet. Mounted on a standard DIN rail, it serves as the brain for countless automation and digitalization tasks. To meet the diverse needs of beginners and professionals, we offer the DIN Rail Controller in two generations.
**1. The Classic DIN Rail Controller (Based on ESP32)**
**The proven all-rounder for beginners.**
This version is the perfect starting point for the world of digital agricultural technology. Based on the ESP32 microcontroller, proven millions of times over, it offers solid dual-core performance for a wide range of control, regulation, and monitoring tasks.

- **Reliable Performance:** Ideal for standard applications such as controlling relays, reading sensors, or communicating via Wi-Fi and Bluetooth.

---

**2. The new DIN rail controller S3 (based on ESP32-S3)**

**The next generation for performance, connectivity, and AI.**

The DIN rail controller S3 is a significant upgrade and is aimed at users with higher demands. The more modern ESP32-S3 chip not only offers faster processor cores but also future-proof features that open up entirely new application areas.

- **More processing power:** The LX7 cores effortlessly handle more complex algorithms and faster processing cycles.
- **Native USB:** Enables direct and faster communication with the PC, simpler firmware updates via drag and drop, and the ability to log data directly to a USB flash drive.
- **AI Capabilities:** Thanks to integrated vector instructions, the chip is optimized for edge AI applications. This allows machine learning models to be run directly on the controller, for example, for pattern recognition in sensor data for predictive maintenance.
- **Expanded I/O:** More available pins allow for the direct connection of more sensors and actuators without additional expansion boards.

Choose the S3 model if you are planning demanding projects, require maximum performance, or want to prepare your project for future AI applications.
