# ⚙️ Runtime

A runtime system is a type of operating system specifically designed for controlling and monitoring embedded systems. It is used to control and monitor the execution of programs on a controller or processor unit.
4diac FORTE is an open runtime system specifically designed for controlling and monitoring industrial automation systems. It supports the IEC 61499 standard, an international standard for the development of control systems. With 4diac FORTE, developers can create their own function blocks and integrate them into their automation applications. It also enables the management and monitoring of devices on a network, communication between devices, and the control of program execution. 4diac FORTE is therefore a powerful and flexible tool for developing automation applications in industrial automation technology
